# Third-party software and data

TrueRef includes these open-source components, unmodified, in `public/vendor` and `public/csl`:

| Component | Used for | Licence |
|---|---|---|
| [citeproc-js](https://github.com/Juris-M/citeproc-js) | Formatting references in each style | CPAL 1.0 / AGPL 3.0 (dual) |
| [mammoth.js](https://github.com/mwilliamson/mammoth.js) | Reading Word (.docx) files in the browser | BSD 2-Clause |
| [PDF.js](https://github.com/mozilla/pdf.js) | Reading PDF files in the browser | Apache 2.0 |
| [CSL styles](https://github.com/citation-style-language/styles) (Cite Them Right Harvard, APA 7th, Chicago author-date, MLA 9th, IEEE, NLM/Vancouver) | Style rules | CC BY-SA 3.0 |
| [CSL locales](https://github.com/citation-style-language/locales) (en-GB, en-US) | Language terms | CC BY-SA 3.0 |

Optional online lookups use the public [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/).
